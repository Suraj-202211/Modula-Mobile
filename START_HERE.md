# Modula Mobile — Quick Start

## To play Minecraft:

### Step 1 — Install requirements
- Node.js: https://nodejs.org (download LTS)
- Java 17: https://adoptium.net (download Temurin 17)

### Step 2 — Start bridge server
Windows: double-click start-bridge.bat
Mac/Linux: run ./start-bridge.sh in terminal

Keep the terminal window OPEN while playing.

### Step 3 — Open Modula Mobile
Open index.html in your browser
OR run: npm run dev

### Step 4 — Play!
1. Sign in (Microsoft or Offline)
2. Go to Versions → Download a version
3. Go to Home → Hit PLAY
4. Minecraft launches for real!
